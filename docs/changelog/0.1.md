# 0.1.x

`@standhigher/bshopify` 的 0.1 系列变更。只记录功能或行为变化；纯文档发布不列入。

## 0.1.6 - 2026-09-10

### Fixed

- `app dev` 带 `--reset` 等额外 Shopify 参数时，仍使用所选 `configFiles` 环境（默认 `dev`）并转发给 Shopify CLI。此前会省略 `--config`，Shopify CLI 会改写上次用过的配置文件。
- `configFiles` 指向 `shopify.app.toml` 时也会传 `--config shopify.app.toml`，不再依赖 Shopify CLI 的上次配置。
- 透传参数中的 `--config` / `-c` 会被忽略；请用 bshopify 的 `-c, --config <key>` 选择 `configFiles` 环境。

## 0.1.5 - 2026-09-09

### Fixed

- `app dev` / `app deploy` 注入后刷新 git index，避免编辑器和 Source Control 在开发期间把注入值显示成工作区改动。

## 0.1.4 - 2026-09-08

### Fixed

- `app deploy` 结束后按完整 token 还原注入值，不再做子串替换。避免 Shopify 写入的 wasm 路径等被注入值污染，同时保留平台写入的 `uid` 等其它改动。

## 0.1.2 - 2026-09-07

### Fixed

- `app dev` / `app deploy` 注入期间遇到 Ctrl+C、SIGTERM、SIGHUP 时，会先取消 Shopify 子进程并还原占位符，再退出。此前 Node 会立刻退出并跳过异步清理，注入值会留在工作区。

## 0.1.1 - 2026-09-04

首次公开发布。

### Added

- CLI 入口 `bshopify` / `bs`；未接管的命令透传官方 Shopify CLI。
- `app init`：接入项目，生成 `bshopify.config.mjs`、`extensions/*/__entry.js`、gitignore、git clean filter 和 pre-commit hook。支持 `--check` / `--cwd`，不改写 `package.json`。
- `app dev`：按 `configFiles` 环境注入后执行 `shopify app dev`。
- `app deploy`：注入后执行 `shopify app deploy`，含占位符校验、确认流程和 `--dry-run`。
- `app clear`：删除 bshopify 生成文件，还原接入前状态。
- `envFiles`：把项目内 JSON/TOML 注入到 `__entry.js` 的 `ctx.<key>`。
- 未改动的占位 `__entry.js` 在 `dev` / `deploy` 时跳过，不加载、不注入。
- TOML 注入使用 `#` 行注释 marker，保持文件为合法 TOML。
- git clean filter：`git add` 时还原注入值，避免进入暂存区。
- init 生成的 config / entry 使用自包含 JSDoc 类型，全局安装时编辑器也能补全和校验。
